# Sam Sahotra — Official Artist Website

Next.js App Router, React, CSS. Node.js 20.9 or newer.

Run npm install, npm run dev, npm run build. Optional: npm run artwork downloads original release covers. Remote covers are retained as a fallback. Confirm rights to self-host artwork. The original transparent PNG is in public/brand/sam-sahotra-logo.png. Spotify points to artist search pending verification of the direct artist profile. Two video cards link to official channel search results. Custom domain setup is separate from Vercel deployment.
